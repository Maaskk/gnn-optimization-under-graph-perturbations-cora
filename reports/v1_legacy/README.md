# Archived Baseline Reports

This directory preserves early report artifacts and the user-supplied PDF context.

Important interpretation limits:

- The early baseline used one seed: 42.
- The early baseline used 200 epochs and Cora only.
- The early baseline used one fixed hyperparameter protocol.
- The early baseline used attribute corruption at severities 0.05, 0.10, 0.20, and 0.30.
- The early baseline measured models trained after perturbation, not clean-trained models evaluated under inference-time corruption.

The final report is the reference for scientific claims.
