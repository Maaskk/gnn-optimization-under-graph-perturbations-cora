# Legacy V1 Reports

This directory preserves the original V1 report artifacts and the user-supplied PDF context.

Important interpretation limits:

- V1 used one seed: 42.
- V1 used 200 epochs and Cora only.
- V1 used one fixed hyperparameter protocol.
- V1 feature noise was Gaussian noise with sigma values 0.05, 0.10, 0.20, and 0.30.
- V1 measured models trained after perturbation, not clean-trained models evaluated under inference-time corruption.

The V2 report should supersede these files for scientific claims.
